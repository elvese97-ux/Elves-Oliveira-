# Quiz OBA Nível 3 🌙⭐

Um quiz interativo sobre astronomia para o programa OBA (Olimpíada Brasileira de Astronomia) Nível 3.

## 📋 Descrição

Este projeto apresenta um quiz educativo com 5 perguntas sobre conceitos fundamentais de astronomia, incluindo:
- Fases da Lua
- Eclipses
- Movimentos da Terra
- Telescópios
- Características das estrelas

## 🎮 Funcionalidades

- ✅ Interface clara e intuitiva
- ✅ 5 questões sobre astronomia
- ✅ Sistema de pontuação automático
- ✅ Design responsivo com tema escuro
- ✅ Navegação simples entre questões

## 🚀 Como Usar

1. Abra o arquivo `quiz.html` em seu navegador
2. Leia cada pergunta com atenção
3. Clique na resposta correta
4. Avance automaticamente para a próxima questão
5. Veja sua pontuação final ao término

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📝 Perguntas do Quiz

1. **Qual é a causa das fases da Lua?**
   - Sombra da Terra
   - **Posição relativa Sol-Terra-Lua** ✓
   - Rotação da Lua
   - Nuvens

2. **Por que não ocorre eclipse todo mês?**
   - Lua é pequena
   - **Órbita inclinada da Lua** ✓
   - Sol muda de lugar
   - Terra gira rápido

3. **Qual movimento causa o dia e a noite?**
   - Translação
   - **Rotação** ✓
   - Gravidade
   - Inclinação

4. **Qual telescópio usa espelhos?**
   - Refrator
   - **Refletor** ✓
   - Lunar
   - Solar

5. **Qual estrela é mais quente?**
   - Vermelha
   - **Azul** ✓
   - Amarela
   - Laranja
